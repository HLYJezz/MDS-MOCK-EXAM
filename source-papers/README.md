# Source papers

Drop the original exam papers in this folder — PDFs, Word documents, or photos/scans
of printed papers. Anything readable is fine.

They are **not** part of the website. Nothing in this folder is loaded by the site or
shown to anyone sitting an exam; it is only the raw material used to write the question
files in `data/`.

## How to upload from the GitHub website

1. Open this folder on GitHub.
2. Click **Add file → Upload files**.
3. Drag the papers in (you can select many at once) and click **Commit changes**.

## What helps

If the answer key, time allowed or pass mark is not written on the paper itself, say so
in the message when you upload — or add a plain text file next to the papers with those
details.
