# The study buddy

Photos that appear in the corner when someone has been staring at one question
for a while. **Drop them in this folder** — nothing else needs changing, and the
site picks them up on its own.

## Naming

Name them in order, starting at 1:

```
companion-1.png
companion-2.png
companion-3.png
```

`.jpg`, `.jpeg` and `.webp` work too — `companion-1.jpg`. The site looks for `companion-1`, then
`companion-2`, and so on until it finds a gap, so **do not skip a number**:
`companion-1` and `companion-3` with no `-2` means only the first is used.

When there is more than one, a random one turns up each time. With none at all,
the site falls back to a drawn cat, so the feature never breaks.

## What makes a good one

- **At least 800px wide.** It arrives filling the screen before it shrinks into
  the corner, so a small photo will look soft during the entrance.
- **The face near the middle.** It is shown as a circle, so anything in the
  corners of the picture gets cropped away.
- A few hundred KB each. These download with the exam page.

Anyone whose face is in one of these should be happy to be there — it appears to
everyone who uses the site.
