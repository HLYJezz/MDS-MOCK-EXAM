# The face behind the IT card

Tap the IT card on the credits page seven times in a row and it turns over to
show a photo from this folder. **Drop photos in here** — nothing else needs
changing.

## Naming

Same rule as the study buddy:

```
face-1.jpg
face-2.jpg
```

`.png`, `.jpeg` and `.webp` work too. The search stops at the first missing
number, so **do not skip one**. With several in here, a random one turns up
each time.

**With this folder empty the card does nothing at all** — no half-flip, no
broken picture. So the easter egg only exists once there is a face to show.

## What makes a good one

- **The card is a wide, short letterbox** — about 2:1 — so the photo is cropped
  to a band across it. The band sits a little above centre, where a face
  usually is, but a full-length photo will lose everything but a strip.
- **At least 700px wide.** The card is about 340px across on a big screen, so
  twice that keeps it sharp on a retina one.
- The photo is nothing to do with the exams, so it is only fetched once someone
  has actually earned the flip.
